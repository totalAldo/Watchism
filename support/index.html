Watchism Support

Support page for the Watchism iPhone app.

Watchism is an iPhone-only app for disciplined reference time and private watch collection management. No account is required to use the app.

Download Watchism on the App Store: https://apps.apple.com/us/app/watchism/id6760947199

2. What Watchism Does

  • shows a disciplined local reference clock using a selectable primary source of NTP, HTTPS Date, or Roughtime, followed by enabled fallback sources
  • stores watch collection records, notes, photos, pricing, valuations, boutique and dealer records, wear logs, Watch Box sort and arrangement preferences, wear-log sort preferences, and timing observations on-device
  • lets you keep a manual Watch Box arrangement or sort the grid by attributes without changing other watch lists
  • lets you manage each watch's saved wear-log history with recency or duration sorting, backdated records, edits, and deletes
  • supports wishlist management, browser-assisted watch discovery, and image import workflows

3. Common Troubleshooting

  • Camera not available: confirm that Camera access is allowed for Watchism in iPhone Settings.
  • Photos not importing: confirm that Photo Library access is allowed and that the selected item is still available in Photos. If the item is stored only in iCloud Photos, approve the Watchism consent prompt and make sure the device can download it.
  • Astronomy data missing: moon phase works without location. Enable astronomy location inside Watchism if you want local sunrise, sunset, twilight, solar noon, and daylight context.
  • Watch Box order: open the Sort menu in the Watch Box to choose Manual, Brand & Name, Newest Added, Oldest Added, Last Worn, Most Worn, or Least Worn. Choose Manual to show the Reorder button for custom grid arrangement. The saved manual arrangement is shared across Watch Box filters, and each filter shows the matching watches in that sequence.
  • Wear logs are not in the order you expect: open the Sort menu on the Wear Log card or Manage Wear Logs sheet to switch between last worn first, oldest first, longest worn, and least worn.
  • Reference source changes: verify your selected primary source and enabled fallback methods in the Sources sheet. Watchism tries the chosen primary source first and then the remaining enabled sources in the displayed order.
  • Browser image import: long-press an image in the in-app browser, then choose whether to add it to the wishlist or attach it to an existing watch. The embedded browser uses non-persistent website data, and image downloads do not forward browser cookies.

4. Permissions Used by the App

  • Camera: only when you choose to take a watch photo.
  • Photos: only when you choose to import or link a photo. Watchism shows consent copy before opening Photos because selected iCloud Photos assets may be downloaded by iOS for import, preview caching, review, crop, or analysis.
  • Contacts: only when you choose to link a boutique advisor.
  • Location: only when you enable astronomy location for solar events; moon phase remains available without location.

5. Privacy

Watchism is designed to keep watch data on-device. For privacy details, see the Watchism Privacy Policy.

6. App Review Information

If Apple App Review needs to verify app behavior, the following points are relevant:

  • no login or account is required
  • collection data and watch images are stored locally on-device unless you explicitly export them
  • network access is limited to configured time-reference endpoints for the selected primary source and any enabled fallback sources such as NTP, HTTPS Date, or Roughtime, plus explicit user actions such as opening sites in Watchism's non-persistent embedded browser or the system browser, importing a selected browser image without browser cookies, or approving selected iCloud Photos asset downloads
