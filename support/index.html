Watchism Support

Support page for the Watchism iPhone app.

Watchism is an iPhone-only app for disciplined reference time and private watch collection management. No account is required to use the app.

1. Contact Support

For support, feature questions, or App Store review follow-up, contact: watchism@totalaldo.com

If you publish an issue tracker or public repository, you can also add it here:
https://www.github.com/totalaldo/Watchism

2. What Watchism Does

  • shows a disciplined local reference clock using configurable time-reference sources
  • stores watch collection records, notes, photos, wear logs, and timing observations on-device
  • supports wishlist management, browser-assisted watch discovery, and image import workflows

3. Common Troubleshooting

  • Camera not available: confirm that Camera access is allowed for Watchism in iPhone Settings.
  • Photos not importing: confirm that Photo Library access is allowed and that the selected item is still available in Photos.
  • Astronomy data missing: enable location inside Watchism if you want local sunrise, sunset, twilight, and moon context.
  • Reference source changes: verify your enabled time sources in the Sources sheet. NTP remains available as the baseline source.
  • Browser image import: long-press an image in the in-app browser, then choose whether to add it to the wishlist or attach it to an existing watch.

4. Permissions Used by the App

  • Camera: only when you choose to take a watch photo.
  • Photos: only when you choose to import or link a photo.
  • Contacts: only when you choose to link a boutique advisor.
  • Location: only when you enable astronomy location features.

5. Privacy

Watchism is designed to keep watch data on-device. For privacy details, see the Watchism Privacy Policy.

6. App Review Information

If Apple App Review needs to verify app behavior, the following points are relevant:

  • no login or account is required
  • collection data and watch images are stored locally on-device unless you explicitly export them
  • network access is limited to configured time-reference endpoints and explicit user actions such as opening sites or importing a selected browser image
